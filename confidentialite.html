Politique de confidentialité de Baskapp

Dernière mise à jour : 14 novembre 2026

Baskapp est une application de saisie de statistiques de basket-ball destinée aux amateurs de basket (parents, entraîneurs, joueurs, dirigeants…) qui veulent des statistiques simples à prendre.

Données traitées

L'application enregistre uniquement les informations que vous saisissez vous-même : noms des saisons et des équipes, prénoms (et éventuellement noms et numéros de maillot) des joueurs, matchs et actions de jeu, et vos réglages d'affichage.

Mémos vocaux : pendant un match, vous pouvez enregistrer de courts mémos vocaux (en maintenant le bouton volume + ou le bouton micro), pour ajouter ensuite les actions que vous n'avez pas eu le temps de saisir. L'application n'utilise le micro que pendant que vous maintenez le bouton, après votre autorisation. Les enregistrements restent sur votre téléphone, ne sont jamais envoyés ni exportés (ni dans les rapports PDF, ni dans les partages), et sont supprimés quand vous supprimez le mémo ou le match. Aucune transcription n'est faite.

Où sont stockées vos données

Toutes ces données sont enregistrées uniquement sur votre téléphone. Baskapp :

  • ne nécessite aucun compte ;
  • n'envoie aucune donnée à un serveur, ni au développeur, ni à des tiers ;
  • ne contient ni publicité, ni outil de mesure d'audience, ni traceur ;
  • ne demande pas d'accès à votre position, à vos contacts ou à votre appareil photo ; le micro n'est utilisé que pour les mémos vocaux, à votre demande (voir ci-dessus).

Version web (dans le navigateur)

Baskapp existe aussi en version web. Elle fonctionne de la même façon : les données sont enregistrées uniquement dans le navigateur de votre appareil (stockage local du site), jamais sur un serveur. Le site sert seulement les fichiers de l'application ; il ne charge rien depuis un serveur tiers (ni police, ni bibliothèque, ni mesure d'audience).

Attention : effacer les données de navigation de ce site supprime vos matchs. Sur iPhone, Safari peut effacer les données d'un site non utilisé pendant 7 jours, sauf s'il a été ajouté à l'écran d'accueil.

Partage

Les données ne quittent votre téléphone que si vous le décidez, par exemple en partageant un rapport PDF via le menu de partage de votre téléphone (WhatsApp, e-mail…). Le destinataire et l'application choisie pour le partage sont alors sous votre responsabilité.

Données concernant des mineurs

Les joueurs peuvent être mineurs (équipes de jeunes). Nous vous recommandons de n'enregistrer que le prénom (et éventuellement l'initiale du nom) et de ne partager les rapports qu'avec les personnes concernées (familles, encadrement de l'équipe).

Conservation et suppression

Les données restent sur votre téléphone (ou dans votre navigateur) tant que vous les conservez. Vous pouvez supprimer un match, une équipe ou une saison dans l'application ; la désinstallation de Baskapp (ou l'effacement des données du site dans le navigateur) supprime toutes ses données.

Ce site

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience. GitHub peut enregistrer des journaux techniques (dont l'adresse IP) pour assurer le service, selon sa propre politique de confidentialité. Les liens vers des sites tiers mènent à ces sites, qui traitent alors vos données selon leurs propres règles.
