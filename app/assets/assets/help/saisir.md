# Saisir pendant le match

L'écran de match se tient en **paysage** ou en **portrait**, au choix (bouton en haut de la première étape de la préparation, ou dans les Réglages). Il reste dans cette position pendant tout le match.

- **En paysage** : à droite, le chrono et vos actions ; au centre, le score et les joueurs sur le terrain ; à gauche, l'adversaire (côtés inversés avec le réglage **Je suis gaucher**, qui ne sert qu'en paysage).
- **En portrait** : de haut en bas, le score, l'adversaire, les joueurs sur le terrain, puis le chrono et vos actions, sous le pouce. Le terrain s'affiche en grand pour placer un tir.

## Une action en deux touches

1. Touchez l'action : **2 pts réussi**, **Rebond déf.**, **Faute**…
2. Touchez le **joueur** concerné.
3. Pour un tir à 2 ou 3 points, touchez l'**endroit du tir** sur le terrain (ou **Passer** / **Sans position**).
4. Pour un panier à 2 ou 3 points, indiquez la **passe décisive** (ou **Pas de passe / ne sait pas**).

Un 3 pts touché dans la raquette est replacé juste derrière la ligne à 3 points, et un 2 pts touché derrière la ligne est replacé juste devant.

## L'adversaire

Une seule touche, sans choisir de joueur : **+1**, **+2**, **+3**, **Faute**, **Rebond off.**, **Rebond déf.**

## Chrono

- **Démarrer / Arrêter le chrono** : en haut à droite en paysage, au-dessus des actions en portrait. Il s'arrête tout seul à 00:00.
- Touchez le **chrono** pour le corriger (−1 min … +1 min). La correction ne l'arrête pas : s'il tournait, il continue de tourner.

## Remplacements

Touchez un joueur **sur le terrain**, puis le joueur du **banc** qui entre. Avant le premier coup de chrono, l'échange modifie simplement le cinq de départ.

## Se tromper n'est pas grave

La dernière action s'affiche sous les joueurs sur le terrain, avec **Annuler**. Les autres actions se corrigent après le match dans le **fil de jeu**.

## Et aussi

- **Temps mort** : choisissez l'équipe ; le chrono s'arrête.
- **Période suivante** : demande une confirmation. En cas d'égalité à la fin, une prolongation est proposée.
- **Fautes** : un message prévient à 4 fautes ; un joueur exclu ne peut plus entrer.
- **Fil de jeu** : toutes les actions, avec le score.
