# Stats et fil de jeu

Après **Terminer le match**, ou en touchant un match terminé sur l'accueil, quatre onglets :

- **Résumé** : résultat, score par période, comparaison des équipes, réussite aux tirs, faits marquants.
- **Joueurs** : le tableau complet. Min = minutes jouées, RO / RD = rebonds offensifs / défensifs, PD = passes décisives, Ctr = contres, Int = interceptions, BP = balles perdues, F = fautes, +/- = écart au score pendant que le joueur est sur le terrain.
- **Tirs** : la carte des tirs (● réussi, ○ raté) et la réussite par zone, pour l'équipe ou un joueur.
- **Fil de jeu** : toutes les actions, période par période.

## Corriger une action

Dans le **fil de jeu**, touchez une action pour changer réussi / raté, le joueur, le passeur, ou pour la **supprimer**. Toutes les stats se recalculent aussitôt.
