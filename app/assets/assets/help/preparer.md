# Préparer un match

La préparation se fait en trois étapes, dans la même position que l'écran de match (paysage ou portrait). Rien n'est enregistré avant **Lancer le match**.

## 1. Match

En haut de l'écran, le bouton **Portrait** (ou **Paysage**) fait tourner l'écran aussitôt. Le choix vaut pour la préparation et le match, et il est gardé pour les matchs suivants.

- **Notre équipe** : la dernière utilisée est déjà choisie.
- **Lieu** et **date** : domicile ou extérieur ; la date est « maintenant » par défaut, touchez-la pour la changer.
- **Adversaire** : tapez quelques lettres pour retrouver une équipe déjà rencontrée, ou tapez un nouveau nom puis **Créer « … »**.

## 2. Convocation

Cochez les joueurs présents. La convocation du **dernier match** est reprise automatiquement ; **Tout cocher** et **Comme le dernier match** font gagner du temps. Il faut au moins autant de convoqués que de joueurs sur le terrain.

## 3. Cinq de départ

Touchez les joueurs qui commencent le match. Les **numéros de maillot** sont facultatifs : ceux du dernier match sont proposés, **Effacer les n°** les retire.

Ensuite : **Lancer le match**.
